# libpjsua2maui - pjsip bindings for .NET MAUI

## Installation

Install the package (on solutions that targets only android and/or ios) with `dotnet add package libpjsua2maui --version 2.17.0.3` for apps targeting Android, iOS, MacCatalyst and Windows.
